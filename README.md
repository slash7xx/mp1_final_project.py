# NPC PROJECT
This is my MP1 NPC project


## 🌟 Highlights

This project can both let you interact with npcs, and generate them.
It features over 20 different npcs, and they all have random traits.


## Overview
This software uses python to create a npc generator. It features import random and import sys. Both are important, as random can randomize the traits, leading to a fun way to generate different npcs each time. Sys allows me to control the runtime
and used to kill the program if certain conditions are met. There are multiple lists, as well as multiple variables using range to help generate random numbers. There are also phrases that the npc says if you talk to them. Those phrases were given
by volunteers and are quite hilarious.

## Uses
This software can be used to help generate npcs for a game and is able to support a small interaction system. It can be something that generates different characters for a project of some sort.

## How to use
Press the little play button in the top right corner. The program will ask if you want to generate npcs and will also ask how many to generate. The npcs you generate will ask if you want to talk to them and you get to learn a bit about the npc if you do
